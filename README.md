# Courseo Frontend

Frontend for the University of Wollongong study plan generator [Courseo].  
Paste a SOLS enrolment and get handbook-aware study advice via an LLM.


## Getting Started

### Local Setup

```bash
# 1. Clone and enter the repo
git clone <repo-url>
cd courseo-frontend

# 2. Install dependencies
npm install

# 3. Run the application
npm run dev
```

| URL | Description |
|-----|-------------|
| `http://localhost:5173/` | Courseo interface |
